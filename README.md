# Student Management System

A simple CRUD application built using Node.js, Express.js, and MongoDB.

## 📌 Project Description

This project demonstrates database integration by connecting a backend application with MongoDB and performing CRUD (Create, Read, Update, Delete) operations on student records.

## 🚀 Features

* Add a new student
* View all students
* Update student details
* Delete a student
* MongoDB database integration

## 🛠 Technologies Used

* Node.js
* Express.js
* MongoDB
* Mongoose

## API Endpoints

### Create Student

POST /students

### Get All Students

GET /students

### Update Student

PUT /students/:id

### Delete Student

DELETE /students/:id

## ▶️ How to Run

1. Install dependencies

npm install

2. Start MongoDB

3. Run the server

node server.js

4. Open Postman and test the API endpoints.
